# Predictive Analytics Using Historical Data

## 🚗 Automobile Sales Forecasting

This project uses historical automobile sales data and machine learning techniques to predict future automobile sales.

## 🎯 Objectives

- Analyze historical automobile sales
- Identify factors affecting sales
- Build predictive machine learning models
- Compare model performance
- Forecast future automobile sales

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Machine Learning
- Predictive Analytics

## 📊 Dataset

The dataset contains:

- Advertising Spend
- Average Vehicle Price
- Fuel Price
- Economic Index
- Sales Units
- Date information

## 🤖 Machine Learning Models

Two models were compared:

1. Linear Regression
2. Random Forest Regression

## 📈 Model Performance

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | 34.91 | 41.56 | 0.488 |
| Random Forest | 49.80 | 62.21 | -0.149 |

### Best Model

**Linear Regression**
